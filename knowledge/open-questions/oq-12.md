# OQ-12 — นิยาม "small execution wave" และเกณฑ์รวม task ใน session เดียว

> เขียนโดย `business-analyst` · สถานะ: closed 2026-10-05 · สารบัญ: `index.md`

## คำถาม

spec ข้อ 13, 18, 22 (REQ-012, REQ-015, REQ-016):

1. execution wave คืออะไร: (ก) ชุด task ที่ runnable และ dispatch รอบเดียวกัน (ข) task ใน phase เดียวกันของ `plan\index.md` (ค) PM กำหนดเองใน plan (ง) อื่นๆ
2. "diff ไม่ใหญ่" / "task ใหญ่" วัดด้วยอะไร และเกณฑ์เท่าไร (เช่น จำนวนไฟล์/บรรทัด) — ยังไม่มีตัวเลข
3. ใครตัดสินว่า task เกี่ยวกัน / security-sensitive พอจะแยก review: PM ระบุใน plan, orchestrator ตามกฎ, หรือคน
4. multi-task worker session (REQ-012 เกณฑ์ 5 ข้อ): ใครตัดสินว่าผ่านเกณฑ์ — PM ระบุใน plan หรือ orchestrator
