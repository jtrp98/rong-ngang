# OQ-19 — สถานการณ์ที่ spec เน้นเป็น human gate ใหม่หรือรวมใน gate เดิม

> เขียนโดย `business-analyst` · สถานะ: closed 2026-10-05 · สารบัญ: `index.md`

## คำถาม

spec ข้อ 35 "Human gates คงเดิม + เน้น" — บางข้อจับคู่กับ gate เดิมได้ (ambiguity → gate 1, destructive migration → gate 2/6, fail ซ้ำ → gate 4, security-sensitive → gate 5) แต่ 3 ข้อไม่มีคู่ชัด:

1. "architecture decision สำคัญ" — เป็น gate ใหม่ หรือรวมใน gate 2 (schema/breaking contract)? และใครชี้ว่า "สำคัญ"
2. "release risk สูง" — gate ใหม่ หรือรวมใน gate 6/7?
3. "production incident impact สูง" — release นี้ยังไม่มี production (รัน local) — อยู่ใน R1 หรือ backlog?
