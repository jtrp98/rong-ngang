# REQ-008 — Solo mode: ขับ pipeline แบบ manual ใน coding agent session

นอกจาก orchestrated mode ระบบต้องมี **solo mode**: ผู้ใช้เปิด coding agent session หนึ่งตัว (เช่น ZCode, Claude Code) ที่โหลด pack ของระบบ (12 role prompts, templates, policies, ตาราง tier) แล้วให้ session นั้นขับ pipeline แบบ manual — สวม role ทีละตัวตามลำดับ, หยุดถามผู้ใช้เองที่ human gate, บันทึก who/when ของการอนุมัติลงเอกสารเอง — โดยไม่ต้องมี orchestrator/Web UI (นี่คือรูปแบบที่ sta2 ใช้ และที่โปรเจกต์นี้ทำงานไปตลอด)

นิยามตามเจ้าของ (2026-10-04): solo mode คือ **การใช้ prompt แบบที่ sta2 ทำ without orchestrator and web — ใครก็ใช้ได้** และ release นี้ต้องรองรับ **4 coding agents: claude, codex, antigravity, zcode**
