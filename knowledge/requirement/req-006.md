# REQ-006 — human gate ผูกกับเจ้าของ และระบบวิ่งหาเจ้าของเอง

human gate ทั้ง 7 จุดของ STA (business choice, schema/breaking contract, UX sign-off, QA Critical/รอบที่ 3, security Critical/Important, deploy จริง, release scope cut) ถูกบังคับโดย orchestrator — ไม่ใช่ความหวังว่า agent จะหยุดเอง — โดยแต่ละ gate มี **เจ้าของที่ผูกไว้ใน config** เมื่อถึง gate ระบบหยุด pipeline แจ้งเจ้าของ (release นี้: แสดงบน dashboard/terminal) บันทึกคำตอบ แล้วไปต่อด้วยคำตอบนั้น

- Source: ผู้ใช้ ("แต่ละ human gate จะผูกกับคนนั้นๆ ให้ตอบ … ก็จะวิ่งหาคนนั้นๆ") · Confirmed by: ผู้ใช้ · Status: confirmed
- **AC-013** — งานที่แตะ gate หยุดจริง ไม่มี agent ทำงานต่อจนกว่าเจ้าของจะตอบ
- **AC-014** — dashboard/terminal ระบุ: gate ไหน, ใครต้องตอบ, คำถามถ้อยคำตรงตัว
- **AC-015** — ย้ายเจ้าของของ gate หนึ่งไปยังคนอื่นได้โดยแก้ config เท่านั้น (รองรับ BA-gate → A, SA/Dev-gate → B ในอนาคต) — release นี้ทุก gate ชี้ที่ผู้ใช้คนเดียว
- **AC-016** — การอนุมัติถูกบันทึก พร้อม ใคร/เมื่อไร ตามที่เจ้าของระบุเอง ระบบไม่เขียนชื่อแทน

ส่วนขยาย R1 (เจ้าของ jtrp98 2026-10-05, spec ข้อ 35): gate 7 จุดคงเดิม และเน้นเป็นพิเศษ — requirement ambiguity ที่ business impact สูง (gate 1), destructive migration (gate 2/6), QA/implementation fail ซ้ำ (gate 4 — รอบที่ 3 ที่ fail, REQ-021), security-sensitive change (gate 5) · **ห้าม agent loop ไม่จำกัด** (REQ-021 AC-071)

รวมเข้า gate เดิม — **จำนวน gate คง 7** (OQ-19 — เจ้าของ jtrp98 2026-10-05):
- architecture decision สำคัญ → SA ส่ง `NEEDS_HUMAN` → gate 2 ถ้าแตะ schema/contract, ไม่แตะ → gate 1
- release risk สูง → แสดงที่ gate 6/7
- production incident impact สูง → ไม่อยู่ใน R1 (ยังไม่มี production) → backlog
- การเพิ่ม gate ใหม่ = เปลี่ยนกติกา human gate 7 จุด ต้องให้เจ้าของยืนยันแยก

- **AC-078** — handoff ของ SA ที่เป็น `NEEDS_HUMAN` เรื่อง architecture ขึ้นบน dashboard เป็น gate 2 เมื่อแตะ schema/contract และเป็น gate 1 เมื่อไม่แตะ — ไม่มี gate หมายเลขที่ 8

- **AC-072** — task ใน parallel run (REQ-013) ที่ถึง gate หยุดเฉพาะงานที่ขึ้นกับ gate นั้น; ทุก gate ที่ค้างแสดงพร้อมกันบน dashboard ครบทุกตัว (สมมติฐาน — ยังไม่ยืนยัน)
