## กติกาทางธุรกิจ

หลักการ: **Session = working memory ชั่วคราว · Artifact = project memory · Orchestrator state = runtime state** (REQ-020)

- ความรู้ของโปรเจกต์ (requirement/design/plan/test/review/qa/security/deploy) ต้องอยู่ในไฟล์ artifact ของ role เจ้าของเท่านั้น — ห้ามใช้ conversation ยาวของ session ใดเป็น source of truth
- session ที่ต้องการความรู้เก่า อ่านจาก artifact ไม่ใช่จาก conversation เก่า
- ปิด/เปิดระบบใหม่ได้โดยไม่เสียความรู้ของโปรเจกต์
- คงของเดิม: role prompt, โครง split docs (DES-014), การอ่าน exact path, ownership, human gates, policies
