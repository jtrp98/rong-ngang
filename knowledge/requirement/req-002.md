# REQ-002 — ส่งงานให้ CLI หลายค่าย (multi-camp)

ระบบเรียกใช้ CLI ของค่ายอื่นได้จริงอย่างน้อย 3 ตัว: **Claude Code** (`claude`), **OpenAI Codex** (`codex`), **Google Antigravity** — โดยมี adapter ต่อ camp แปลงบรีฟ + role prompt + tier เป็น argument/flag ของ CLI นั้นๆ

- Source: ผู้ใช้ (คำสั่งเริ่มต้น: "ไปเรียกใช้ cli ของ AI ค่ายต่างๆ เช่น Claude, Codex, Antigravity") · Confirmed by: ผู้ใช้ · Status: confirmed
- ตัดสินใจแล้ว (OQ-2 ปิด 2026-10-04): release นี้ **ทุก role default รันที่ camp claude** — codex/antigravity พร้อมใช้ทันทีเมื่อแก้ routing config โดยไม่ต้องแก้โค้ด
- **AC-004** — งานชุดเดียวกัน (role + brief เดียวกัน) สั่งรันบนทั้ง 3 CLI ได้ โดยไม่ต้องแก้บรีฟ
- **AC-005** — log/แดชบอร์ดระบุได้ว่า task นี้ถูกส่งให้ camp ใด model ใด effort ใด และเพราะอะไร (tier หรือ override)
