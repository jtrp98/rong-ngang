## Scope

- เขียนเฉพาะ cell Status ตาม `Decision.statusWrites` ค่า `verified`/`blocked` (ไม่เขียน `pending`)
- 🔒 (DES-007, Rev 11): `Decision.securityMarks[{phase, reason}]` (R23) → เพิ่ม 🔒 ในแถว Phase ของ `## Phases` **เพิ่มอย่างเดียว ไม่ลบ** · มีอยู่แล้ว → no-op
- ทั้งสองแบบใช้ขั้นตอน DES-007 §Status write-back (+ self-write journal) · resume: `securityGate` ใน `sessions[].handoff` ที่ยังไม่อยู่ใน doc → เขียนซ้ำ · หาแถว Phase ไม่เจอ → ไม่เขียน + แจ้ง dashboard (ไม่ hold) — DES-007
- มี session ที่ claim `plan/**` active → เลื่อนจน session จบ · ค่าเดิมไม่ตรง / หาแถวไม่เจอ → ไม่เขียน + hold `status-conflict`
- ใช้เฉพาะ orchestrated mode (solo: qa-engineer เขียนเอง)
- Write paths: `agent-team/src/core/status-writer.ts`, `agent-team/test/status-writer.test.ts`
- Security-sensitive: yes
