## Goal

หน้า module แสดงงานต่อ task แบบสด — อะไรรันพร้อมกัน, รออะไร, ค้างที่ใคร — และให้คนกด retry โดยพิมพ์ชื่อตัวเอง

## Scope

- ตาราง 1 แถวต่อ task: Status (จากเอกสาร) · step · attempt · session · hold · `waitingFor` · ตัวนับ `n / maxParallelSessions`
- แผง Waiting on Human ป้ายที่มา `doc` / `gate N` / `hold:<reason>` ครบทุกตัวพร้อมกัน · แถบ "ต้อง migrate" + "dispatch ทีละตัว" เมื่อ plan legacy · สถานะ Feature QA ต่อ phase
- หน้า session: contextFiles, writeAudit, priorSession, logTail · ปุ่ม retry (ช่อง `by` บังคับ, `note` optional) · อัปเดตด้วย SSE ต่อ task
- ข้อความจาก agent/log แสดงเป็น text (escape) ไม่ใช่ HTML
- Write paths: `agent-team/ui/**`
- Security-sensitive: yes (แสดงข้อความ untrusted)

## Out of Scope

- framework/bundler/CDN · server logic (อ่าน contract จาก BE-023 ที่ build แล้วจริง — `policies\agent-boundaries.md` §3) · ปุ่ม reset ตัวนับ · แก้ Status

## Expected Output

- ส่วนขยายของ single page เดิม (FE-001) ที่ `code\agent-team\ui\`

## Acceptance

- เปิด `127.0.0.1:7800` ระหว่าง fixture run — หลายแถว running พร้อมกัน + `n / max` (AC-043, AC-045) · step/attempt/session ต่อ task และ session ไม่ซ้ำ (AC-065, AC-040)
- แก้ Depends ใน plan → แถว runnable เปลี่ยน + `waitingFor` อธิบาย (AC-037) · blocker: task อื่นยัง running (AC-064) · gate หลายตัวแสดงครบ (AC-072, AC-014) · legacy มีแถบ migrate (AC-074)
- หน้า session แสดงรายชื่อไฟล์ใน packet (AC-047) + priorSession หลัง restart (AC-066) · ปิด/เปิด orchestrator แล้ว Status ตรง plan (AC-034)
- retry ต้องพิมพ์ชื่อ · ข้อความ `<script>` ใน logTail แสดงเป็นตัวอักษร · ไม่มี external resource
