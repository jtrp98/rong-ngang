# BE-023 — Task dashboard API + human retry (DES-022)

> ≤ 4 KB · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

endpoint ให้คนเห็นงานต่อ task (Status จากเอกสาร + runtime จาก orchestrator) ว่าอะไรรัน/รอ/ค้างเพราะอะไร และปลด hold ด้วยปุ่ม retry ที่ระบุชื่อผู้กด

- REQ-020 (AC-065, AC-066), REQ-013 (AC-043, AC-045), REQ-011 (AC-037, AC-074), REQ-006 (AC-014, AC-072), REQ-014 (AC-047), REQ-019 (AC-064), REQ-010 (AC-034), REQ-012 (AC-040)
- DES-022, DES-009

## Scope

- 3 endpoint ตามตาราง DES-022: `GET /api/modules/<name>/tasks`, `POST /api/modules/<name>/tasks/<taskId>/retry`, `GET /api/sessions/<sessionId>`
- Status จาก `plan\index.md` เท่านั้น · step/attempt/session จาก TaskRuntime · `waitingFor` (Depends ที่ยังไม่ satisfied + เหตุคิว) · `waitingOnHuman` รวม doc/gate/hold ครบทุกตัวพร้อมป้ายที่มา · module ไม่มี run → จากเอกสารล้วน
- retry: ปลดเฉพาะ hold ที่ DES-022 อนุญาต → event `human-retry` · ไม่ reset ตัวนับ · บันทึก `{by, note, at}` ตามที่ผู้ใช้พิมพ์ · hold ที่ห้าม → 409 · `by` ว่าง → 400
- 🔒 POST ตรวจ `Origin` = `http://127.0.0.1:<port>` + Host check ตาม DES-009
- Write paths: `agent-team/src/web/tasks-api.ts`, `agent-team/src/web/server.ts`, `agent-team/test/tasks-api.test.ts`
- Security-sensitive: yes

## Out of Scope

- UI (FE-002) · reset ตัวนับ · ปลด `design-change`/`requirement-change`/gate ที่ยัง open · แก้ Status

## Expected Output

- endpoint ที่ build แล้วจริง + ตัวอย่าง response ให้ FE-002 อ่าน

## Acceptance

- รัน server จริงกับ fixture run — tasks คืนครบ field DES-022 · หลายแถว running + `active`/`maxParallelSessions` (AC-043, AC-045) · attempt/session ไม่ปรากฏใน module docs (AC-065) · legacy → `needsMigration` (AC-074)
- แก้ Depends ใน plan → `waitingFor` เปลี่ยน (AC-037) · blocker: task อื่นยัง running (AC-064) · gate/hold/doc ครบใน `waitingOnHuman` (AC-072, AC-014)
- session endpoint มี `contextFiles` (AC-047) + `priorSession` (AC-066) · session ต่อ task ไม่ซ้ำ (AC-040) · ปิด/เปิด orchestrator แล้ว Status ตรง plan (AC-034)
- retry: Origin ผิด / `by` ว่าง → ปฏิเสธ · hold ที่ห้าม → 409 · ตัวนับไม่ reset
