# REQ-014 — Minimum context ต่อ session และอ้างอิงด้วย ID

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

## กติกาทางธุรกิจ

- แต่ละ session ได้เฉพาะ **Minimum Context Required**: task file + REQ/DES ที่ task อ้าง + โค้ดที่เกี่ยว
- โดย default ห้ามส่ง: requirement/design/plan ทั้งชุด, QA/review ทุก round, conversation history
- เอกสารอ้างกันด้วย ID (REQ/AC/DES/task id/TP/REV/QA) แทนการ copy เนื้อหา — ตัวโหลดเปิดเฉพาะไฟล์/section ที่ถูกอ้าง
- คงของเดิม: อ่าน index-first แล้วเปิด exact path (DES-014, `policies\documentation.md` §5) และ two-way rule

- **AC-046** — packet ของ engineer task มีเฉพาะ task file + ไฟล์ REQ/DES ที่ task อ้าง (+ index ที่จำเป็น) — ไม่มี req/des ที่ task ไม่อ้าง, ไม่มี review/qa round ที่ไม่เกี่ยว, ไม่มี conversation history
- **AC-047** — log ของ dispatch แต่ละครั้งแสดงรายชื่อไฟล์ที่อยู่ใน packet ให้คนตรวจ AC-046 ได้
- **AC-048** — ID ที่ถูกอ้างใน task/defect/review แล้วหาไฟล์ไม่เจอ → ระบบไม่ dispatch และแจ้งให้คนเห็น (fail-closed)
