# REQ-011 — `plan\index.md` เป็น work graph (Depends + Status แหล่งเดียว)

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

## กติกาทางธุรกิจ

- project-manager เป็นเจ้าของ work graph: แตก feature เป็น task ที่ verify ได้อิสระ, กำหนด owner / dependency / scope / acceptance / handoff — ไม่บอก implementation detail ที่ FE/BE ตัดสินเองได้
- `plan\index.md` เป็น source of truth ของ task graph: ตาราง `Task | Name | Owner | Phase | Depends | Status` — **Depends อยู่ใน index**
- **Owner ห้ามเป็น `reviewer`/`security` (OQ-20)** — ดู REQ-015
- task file = contract ของงาน สั้น มีหัวข้อ: Goal, References (REQ/DES), Scope, Out of Scope, Expected Output, Acceptance, Dependencies, Handoff
- **ไม่มี Status ใน task file**
- **ผู้เขียน Status (OQ-14):** orchestrated mode — orchestrator คัดลอกจาก verdict ของ qa-engineer (AC-073) · solo mode — qa-engineer เขียนเหมือนเดิม · ค่าที่ลงได้: `pending`/`verified`/`blocked` เท่านั้น
- **รูปเดิม (OQ-15):** ไม่ migrate ทั้งก้อน — PM amend ตอน replan เฉพาะ module ที่มีงานเปิด, task verified ไม่แตะ (AC-074)

- **AC-036** — ตาราง task ใน `plan\index.md` มีคอลัมน์ Task, Name, Owner, Phase, Depends, Status ครบทุกแถว
- **AC-037** — แก้ค่า Depends ใน `plan\index.md` อย่างเดียว แล้วรายการ task ที่ runnable บน dashboard เปลี่ยนตาม (ไม่ต้องแก้ task file)
- **AC-038** — task file ที่สร้างใหม่ทุกไฟล์มี 8 หัวข้อข้างบนและไม่มีฟิลด์ Status; ถ้าพบ Status ใน task file ระบบไม่ใช้ค่านั้นเป็นสถานะและแจ้งว่าไม่ตรงรูป
- **AC-039** — Depends ที่อ้าง task id ที่ไม่มีอยู่ หรือเป็นวงวน → ระบบไม่เริ่ม task ที่เกี่ยวข้องและแสดงปัญหาให้คนเห็น (สมมติฐาน — ยังไม่ยืนยัน)
- **AC-073** — orchestrated mode: ทุกการเปลี่ยน Status ใน `plan\index.md` ตรงกับ verdict ใน `qa\` ของ task นั้น, write audit ไม่พบ agent session ใดเขียน Status, และไม่มีค่านอก `pending`/`verified`/`blocked`
- **AC-074** — module ที่ `plan\index.md` เป็นรูปเดิม (`id|status`): dashboard แสดงสถานะได้, ขึ้นธง "ต้อง migrate" และไม่มี task ถูก dispatch พร้อมกัน
- **AC-079** — `plan\index.md` มีแถว Owner = `reviewer` หรือ `security` → orchestrator ไม่ dispatch แถวนั้น และแสดงคำเตือนระบุ task id ให้คนเห็น
