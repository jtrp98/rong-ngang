# REQ-006 — human gate ผูกกับเจ้าของ และระบบวิ่งหาเจ้าของเอง

human gate ทั้ง 7 จุดของ STA (business choice, schema/breaking contract, UX sign-off, QA Critical/รอบที่ 3, security Critical/Important, deploy จริง, release scope cut) ถูกบังคับโดย orchestrator — ไม่ใช่ความหวังว่า agent จะหยุดเอง — โดยแต่ละ gate มี **เจ้าของที่ผูกไว้ใน config** เมื่อถึง gate ระบบหยุด pipeline แจ้งเจ้าของ (release นี้: แสดงบน dashboard/terminal) บันทึกคำตอบ แล้วไปต่อด้วยคำตอบนั้น

- Source: ผู้ใช้ ("แต่ละ human gate จะผูกกับคนนั้นๆ ให้ตอบ … ก็จะวิ่งหาคนนั้นๆ") · Confirmed by: ผู้ใช้ · Status: confirmed
- **AC-013** — งานที่แตะ gate หยุดจริง ไม่มี agent ทำงานต่อจนกว่าเจ้าของจะตอบ
- **AC-014** — dashboard/terminal ระบุ: gate ไหน, ใครต้องตอบ, คำถามถ้อยคำตรงตัว
- **AC-015** — ย้ายเจ้าของของ gate หนึ่งไปยังคนอื่นได้โดยแก้ config เท่านั้น (รองรับ BA-gate → A, SA/Dev-gate → B ในอนาคต) — release นี้ทุก gate ชี้ที่ผู้ใช้คนเดียว
- **AC-016** — การอนุมัติถูกบันทึก พร้อม ใคร/เมื่อไร ตามที่เจ้าของระบุเอง ระบบไม่เขียนชื่อแทน
