# REQ-023 — `rong-ngang-workspace\` เก็บเฉพาะของของ project

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น · กระทบ: **orchestrator + pack** (R2)

## กติกาทางธุรกิจ

project ที่ใช้ rong-ngang มีโครง:

```
<project>\
├── knowledge\<module>\     ← เอกสารของ project (split layout ตาม DES-014 — คงเดิม)
├── rong-ngang-workspace\   ← ของเฉพาะ project นี้ (ไม่ใช่สำเนาสินค้า)
└── target\                 ← โค้ดจริงที่ทีมพัฒนา
```

`rong-ngang-workspace\` เก็บเฉพาะ: (1) **การผูก knowledge / target** ของ project (2) **state + log ของ run** (3) **ค่าที่ project ปรับเอง (override)** ของเจ้าของ gate และ camp / tier / routing — ค่าตั้งต้นของสิ่งเหล่านี้มากับ package (REQ-022); project ที่ต้องการต่างจากค่าตั้งต้นใส่ override ใน `rong-ngang-workspace\`

- Source: เจ้าของ (jtrp98) ในแชท 2026-10-08 + AskUserQuestion 2026-10-08: เก็บอะไร = "ผูก knowledge/target, state + log ของ run" · gate/camp = "ค่าตั้งต้นจาก package + ปรับใน workspace ได้" · โครง knowledge = "knowledge\<module>\ (คงแบบเดิม)" · Confirmed by: เจ้าของ (jtrp98) · Status: confirmed
- ค่าตั้งต้นของเจ้าของ gate ใน package = ผู้ใช้คนเดียวของ project ไม่ผูกชื่อบุคคล (ปัจจุบัน `gates.yaml` ผูก `jtrp98`) — (สมมติฐาน — ยังไม่ยืนยัน; มาจากคำอธิบายตัวเลือกที่เจ้าของเลือก)
- **AC-085** — `rong-ngang-workspace\` ของ project ที่ติดตั้งใหม่มีเฉพาะการผูก knowledge/target (+ override ถ้ามี) และ state/log — ไม่มี role prompt, policy, template หรือ source ของ orchestrator
- **AC-086** — ผู้ใช้ผูก knowledge และ target ของ project ได้ที่ `rong-ngang-workspace\` แล้วทีม (ทั้ง solo และ orchestrated) อ่าน/เขียนเอกสารที่ `<project>\knowledge\<module>\` และพัฒนาโค้ดที่ target ที่ผูกไว้
- **AC-087** — project ที่ไม่มี override ใช้ค่าตั้งต้นของเจ้าของ gate และ camp/tier/routing จาก package · ใส่ override ใน `rong-ngang-workspace\` แล้วมีผลเฉพาะ project นั้น — project อื่นบนเครื่องเดียวกันไม่เปลี่ยน
- **AC-088** — state และ log ของ run อยู่ใน `rong-ngang-workspace\` ของ project ที่รัน — ไม่ปนกับ project อื่น และไม่อยู่ในโฟลเดอร์ package

ยังเปิด: ผู้ใช้ปลายทางเปิด agent session ที่ไหน (ราก project หรือ `rong-ngang-workspace\`) → OQ-21 (ส่ง SA เสนอทางเลือก)
