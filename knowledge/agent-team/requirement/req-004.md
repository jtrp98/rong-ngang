# REQ-004 — กำกับด้วย Tier 1–6

ทุกงานถูกกำกับด้วย tier ตามแนวคิดเดิม: **T1 สงวนไว้ให้คนเลือกเอง ห้าม cast อัตโนมัติ**, แต่ละ role มี default tier (เช่น BA=T3, SA/PM=T2, engineer=T5), task เฉพาะสามารถ override ขึ้น/ลงได้ และ tier → model/effort ต่างกันตาม camp — ตาราง binding เป็นไฟล์ config ที่คนเป็นเจ้าของ (แบบ `model-tiers.yaml`) ไม่ถูกระบบแก้เอง

- Source: ผู้ใช้ ("จะกำกับด้วย Tier 1-6") + `software-team-agents\model-tiers.yaml`, ADR-022 · Confirmed by: ผู้ใช้ (แนวคิด) · Status: confirmed — ตาราง binding ฉบับตั้งต้นยืนยันแล้ว (OQ-4 2026-10-04)
- **AC-008** — task ที่ระบุ tier รันด้วย model/effort ของ tier นั้นตาม camp ที่เลือก และรายงาน `basis` ของการเลือกได้
- **AC-009** — ระบบปฏิเสธ tier ที่ไม่ใช้ได้ (เช่น T1 จากการ cast อัตโนมัติ) พร้อมเหตุผล
- **AC-010** — แก้ไฟล์ binding แล้ว run ถัดไปใช้ค่าใหม่ โดยไม่ต้องแก้โค้ด

**ตาราง binding ฉบับตั้งต้น (ยืนยันแนวทาง OQ-4, 2026-10-04 — ค่าใช้งานจริงอยู่ที่ config file แก้ได้โดยไม่แตะเอกสาร):**
