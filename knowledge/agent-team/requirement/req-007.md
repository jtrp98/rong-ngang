# REQ-007 — งานใหม่ส่งตรงถึง BA เป็นผู้กรอง

ข้อความงานใหม่จากช่องพิมพ์ถูกส่ง**ตรงถึง business-analyst** โดยไม่มีชั้นจัดหมวดแยก — BA เป็นคนตัดสินเองว่าจะ **เพิ่มเข้า module ที่มีอยู่** (amend requirement เดิม) หรือ **สร้าง module ใหม่** (สร้างโฟลเดอร์ + requirement.md) แล้วงานเข้า process เดิม: pipeline ตาม STA + human gates + right-size ตามตาราง "The work is → Run"

- Source: ผู้ใช้ (ข้อความแก้ไข 2026-10-04: "ก็จะส่งตรงให้ BA เป็นคนกรองเอง ว่าจะเพิ่ม module หรือจะสร้างใหม่ หลังจากนั้น ก็เข้า process เดิม") · Confirmed by: ผู้ใช้ · Status: confirmed
- **AC-017** — กดส่งงานใหม่แล้ว BA ได้รับข้อความฉบับเต็มทันที ไม่มีตัวกลางแปลง/จัดหมวด
- **AC-018** — ผลตัดสินของ BA แสดงกลับใน UI: "เพิ่มเข้า module X" หรือ "สร้าง module ใหม่ Y" พร้อมเหตุผลสั้นๆ
- **AC-019** — หลัง BA ตัดสินแล้ว งานเดินตาม process เดิมต่อเองจนถึง human gate ถัดไป
