# REQ-008 — Solo mode: ขับ pipeline แบบ manual ใน coding agent session

นอกจาก orchestrated mode ระบบต้องมี **solo mode**: ผู้ใช้เปิด coding agent session หนึ่งตัว (เช่น ZCode, Claude Code) ที่โหลด pack ของระบบ (12 role prompts, templates, policies, ตาราง tier) แล้วให้ session นั้นขับ pipeline แบบ manual — สวม role ทีละตัวตามลำดับ, หยุดถามผู้ใช้เองที่ human gate, บันทึก who/when ของการอนุมัติลงเอกสารเอง — โดยไม่ต้องมี orchestrator/Web UI (นี่คือรูปแบบที่ sta2 ใช้ และที่โปรเจกต์นี้ทำงานไปตลอด)

นิยามตามเจ้าของ (2026-10-04): solo mode คือ **การใช้ prompt แบบที่ sta2 ทำ without orchestrator and web — ใครก็ใช้ได้** และ release นี้ต้องรองรับ **4 coding agents: claude, codex, antigravity, zcode**

- Source: ผู้ใช้ (2026-10-04: "อยากให้มี solo mode คือ คล้ายๆอันที่ทำอยู่ตอนนี้ pipeline แบบ manual ที่ agent code ใช้งานได้ เช่นคุณ zcode" + "solo mode มันก็คือการใช้ prompt แบบที่ sta2 ทำ without orchestrator and web ใครก็ใช้ได้ … เบื้องต้นอยากให้รองรับ 4 อัน claude , codex , antigravity , zcode") · Confirmed by: ผู้ใช้ · Status: confirmed
- **AC-020** — coding agent session ที่โหลด pack ขับ pipeline ได้: เล่น role ตามลำดับ, จบแต่ละ role ด้วย handoff, หยุดถามผู้ใช้ที่ gate ทุกจุด
- **AC-021** — module ที่เริ่มแบบ solo ทำต่อแบบ orchestrated ได้และกลับกัน — เอกสารและสถานะ (`## Waiting on Human` ใน plan.md) อยู่ในรูปเดียวกันใน knowledge root เดียวกัน
- **AC-022** — solo mode ใช้ตาราง tier เป็นคำแนะนำ model/effort ตอน session spawn subagent ต่อ role (ตาม role default หรือ tier ของงาน)
- **AC-023** — แก้ role prompt/policy ที่จุดเดียวแล้วทั้งสองโหมดได้รับ (แหล่งเดียวกับที่ orchestrator อ่าน — ห้ามแตกสำเนาสองชุด)
- **AC-024** — เปิด solo session ได้กับทั้ง 4 agents (claude, codex, antigravity, zcode) โดยใช้ pack ชุดเดียวกัน (มีจุดเข้าต่อ agent เช่น `.claude/agents`, `AGENTS.md` ฯลฯ — ออกแบบใน design)
