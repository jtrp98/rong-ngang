## คำถาม

spec ข้อ 23 (REQ-017) "หลัง task ทั้งหมดของ feature เสร็จ ต้องมี integration QA":

1. feature หนึ่งตัว = (ก) phase ใน `plan\index.md` (ข) กลุ่ม task ที่อ้าง REQ เดียวกัน (ค) release scope ทั้งก้อน (ง) PM ระบุใน plan

3. user flow ที่ Feature QA ต้องทดสอบ มาจาก test-planner (TP) หรือ QA กำหนดเองจาก REQ
