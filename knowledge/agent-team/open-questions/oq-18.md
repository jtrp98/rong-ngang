# OQ-18 — task ค้างกลางรันตอน restart และรอบแก้ใช้ session เดิมหรือใหม่

> เขียนโดย `business-analyst` · สถานะ: closed 2026-10-05 · สารบัญ: `index.md`

## คำถาม

spec ข้อ 29, 32 (REQ-012, REQ-020) "restart ระบบได้โดยไม่เสียความรู้" และ "same goal + task + local context → same session"

1. orchestrator ปิด/ล่มขณะ task running: (ก) เริ่ม task ใหม่ใน session ใหม่ (ข) resume session เดิมถ้า CLI รองรับ (ค) หยุดถามคน — ร่างปัจจุบัน (ก) (สมมติฐาน — ยังไม่ยืนยัน)
2. ไฟล์ที่ session ค้างแก้ไปครึ่งทางก่อนล่ม ให้ทำอย่างไร (เก็บไว้ให้ session ใหม่ทำต่อ หรือย้อนก่อน)
3. รอบแก้หลัง review/QA FAIL: resume session เดิมของ task (มี local context) หรือเปิด session ใหม่ที่ได้แค่ defect packet + artifact
