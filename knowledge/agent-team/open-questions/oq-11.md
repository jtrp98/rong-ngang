# OQ-11 — retry limit เท่าไร และสัมพันธ์กับ "max two fix rounds" เดิมอย่างไร

> เขียนโดย `business-analyst` · สถานะ: closed 2026-10-05 · สารบัญ: `index.md`

## คำถาม

spec ข้อ 29 "เกิน retry limit → human" (REQ-021) — ของเดิมใน `CLAUDE.md`: "Max two fix rounds per task, then a human decides" และ gate 4 "the third failed round on the same task"

1. retry limit = ค่าเดิม (2 fix rounds, รอบที่ 3 ขึ้น gate 4) หรือค่าใหม่? ร่างปัจจุบันใช้ค่าเดิม (สมมติฐาน — ยังไม่ยืนยัน)
2. review FAIL กับ QA FAIL นับรวมเป็นตัวนับเดียวต่อ task หรือแยกกัน?
3. Feature QA FAIL (REQ-017) และ session ที่ crash (OQ-18) นับเป็น retry ด้วยหรือไม่?
