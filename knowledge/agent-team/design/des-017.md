## DES-017 — `/gituse` slash command (solo mode)

> Budget ≤ 8 KB · เขียนโดย `system-analyst` · 1 contract · schema/resolve ของ `gituse` = DES-015 · การบังคับ = DES-016

> **ไม่อยู่ R1 — เลื่อนไป release ถัดไป (เจ้าของ jtrp98 2026-10-05):** rule ทั้งไฟล์คงไว้ · R1 ไม่มี `.claude\commands\gituse.md` / หัวข้อ `/gituse` ใน `AGENTS.md`

**Traces:** REQ-009 (AC-025, AC-028, AC-029), REQ-008 (AC-023, AC-024), DES-013, DES-015

**Rule:** `/gituse` เป็น slash command ของ coding agent ใน solo mode (OQ-9 (1)) — แก้ key `gituse` ใน `code\sta-config.json` เท่านั้น · ไม่มีใน Web UI/API ของ orchestrator (UI แสดงอย่างเดียว — DES-009)

- **รูปคำสั่ง:** `/gituse` = แสดงตารางทุก knowledge/target: ค่าที่ตั้ง (หรือ "ไม่ตั้ง") · effective · basis (`target|knowledge|default` — DES-015) · `/gituse on|off|unset [<knowledge>] [<target>]` — ไม่ระบุ target = ระดับ knowledge · ไม่ระบุ knowledge: มีตัวเดียว → ตัวนั้น, หลายตัว → ถามผู้ใช้ (ไม่เดา) · `unset` = ลบ key (กลับไปสืบทอด → default เปิด ถ้าไม่มีระดับบนตั้ง)
- **การเขียน:** อ่าน sta-config → แก้ `gituse` จุดเดียว รักษา key/ลำดับอื่นทั้งหมด → เขียน atomic (ไฟล์ชั่วคราวในโฟลเดอร์เดียวกัน แล้ว rename — orchestrator ที่อ่านพร้อมกันไม่เห็นไฟล์ครึ่ง ๆ) → parse ซ้ำยืนยัน
- **ผลลัพธ์:** ตอบ "<knowledge[/target]>: <เดิม> → <ใหม่> (effective <x>) — มีผล run ถัดไป; run ที่วิ่งอยู่ใช้ค่าเดิม" (AC-029)
- **จุดวางใน pack (`code\`):** claude/zcode → `.claude\commands\gituse.md` (custom slash command — `inferred` ยังไม่ตรวจบนเครื่อง) · codex/agy → หัวข้อ `/gituse` ใน `AGENTS.md` ชี้ไฟล์เดียวกัน (instruction-level — `inferred`) · แหล่งความจริงเดียว ห้ามสำเนา (AC-023)

**Inputs/Outputs:** Input: argument ข้างต้น + `code\sta-config.json` · Output: sta-config ที่แก้แล้ว + ข้อความยืนยัน · ไม่มี log/ประวัติ

**Permissions/States/Errors:** ใครก็ใช้ได้ ไม่บันทึกว่าใครสลับ (OQ-9 (2) "setting local") · เป็นการกระทำของ session ตามคำสั่งที่ผู้ใช้พิมพ์เอง — role/AI ห้ามเรียกเองหรือแก้ sta-config เอง (DES-006 deny) · errors: ไฟล์ไม่มี/parse ไม่ผ่าน → ไม่เขียน แนะรัน setup prompt · ชื่อ knowledge/target ไม่พบ → ไม่เขียน แสดงรายชื่อที่มี · argument ผิด → แสดงรูปใช้ · ค่าที่เขียนเป็น JSON boolean เสมอ (ผ่าน validator DES-015)

**Compatibility:** additive — ไฟล์ใหม่ใน pack + หัวข้อใน `AGENTS.md` · **Data/schema · Migration:** แก้ key ที่มีอยู่ใน schema DES-015 — ไม่มี migration

**Security:** ไม่มี secret · trust boundary = ผู้ใช้บนเครื่อง (ไม่มี auth ตามคำตอบ OQ-9) · abuse: AI ใน session สลับเองเพื่อให้สิทธิ์ตัวเอง → prompt ห้าม; orchestrated run ไม่ได้ผลเพราะ freeze (DES-016) แต่ไม่มีประวัติให้ตรวจย้อน — ความเสี่ยงคงเหลือยอมรับตาม OQ-9

**Fallback:** coding agent ไม่รองรับ custom slash command → ผู้ใช้พิมพ์ "/gituse ..." เป็นข้อความ แล้ว session ทำตามหัวข้อใน `AGENTS.md` · หรือแก้ sta-config ด้วยมือ

**Evidence:** OQ-9 (1)(2) + REQ-009 AC-029 (คำตอบเจ้าของ 2026-10-05) · `code\sta-config.json:1-12` (โครงที่ต้องรักษา) · รูป slash command ต่อ agent — `inferred`
