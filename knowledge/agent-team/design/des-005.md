## DES-005 — Role routing (role → camp)

**Traces:** REQ-002 (AC-004, AC-005), REQ-006 (AC-015 แนวคิด "แก้ config เท่านั้น")

**Rule:** เลือก camp ต่อ stage จาก precedence: (1) override ต่อ run ที่ผู้ใช้ระบุใน UI ตอนกดเริ่ม (optional) → (2) `role_routes.<role>.camp` → (3) `defaultCamp` — แนวเดียวกับ `tierCampSelection.ts:27-33` (flag > config > default) แต่ตัดชั้น TTY prompt เพราะระบบนี้ headless ตลอด และ UI ทำหน้าที่แทน ทุก dispatch บันทึก camp ที่เลือก + แหล่งที่มา (`run-override|role-route|default`) ลง StageRecord.basisReason (AC-005)

**Inputs/Outputs:** Input: `routing.yaml`, ชื่อ role. Output: camp id + basis. การเปลี่ยนทุก role มาที่ codex/antigravity ทำได้โดยแก้ routing.yaml อย่างเดียว (OQ-2) — ไม่มีโค้ดแตะ

**Permissions/States/Errors:** camp ที่ไม่รู้จักใน routing.yaml → ปฏิเสธ run ตอน validate ก่อนเริ่ม; camp ที่ CLI ไม่ตอบสนองตอน spawn → DES-002 error path · **Compatibility:** additive · **Data/schema · Migration:** routing.yaml มี `writePaths` ต่อ role ด้วย — ชุดตั้งต้นยืนยันแล้ว 2026-10-04 (OQ-D2 ปิด — ดู DES-006 และ design-archive.md) · **Security:** routing.yaml เขียนได้โดยคนเท่านั้น — agent ถูก deny ผ่าน universal deny ของ DES-006 · **Fallback:** role ที่ไม่มี route → defaultCamp

**Evidence:** `tierCampSelection.ts:16-33` · `requirement.md:39` (OQ-2 ทุก role default claude) · `runtimeRouting.ts:25-34` (แนว precedence ของเดิม — ย่อเหลือ 3 ชั้น)
