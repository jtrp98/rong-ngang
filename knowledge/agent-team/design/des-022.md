# DES-022 — Dashboard ต่อ task (runtime view) + human retry

> Budget ≤ 8 KB · เขียนโดย `system-analyst` · 1 contract · แถวใน `design\index.md` · ส่วนขยายของ DES-009 (server/security เดิม)

- **Traces:** REQ-020 (AC-065, AC-066), REQ-013 (AC-043, AC-045), REQ-011 (AC-037, AC-074), REQ-006 (AC-014, AC-072), REQ-014 (AC-047), REQ-019 (AC-064), REQ-010 (AC-034), REQ-012 (AC-040)
- **Rule:** หน้า module แสดงตาราง task 1 แถวต่อ task · **Status มาจาก `plan\index.md` เท่านั้น** · step/attempt/session มาจาก TaskRuntime (ไม่ลง docs — AC-065) · หลายแถว `execution`/`review`/`qa` พร้อมกันได้ (AC-043) · จำนวน active แสดงคู่เพดาน `n / maxParallelSessions` (AC-045) · แผง **Waiting on Human** = แถว `## Waiting on Human` ของ plan + gate open ทุกตัว + hold ของ runtime — ป้ายที่มาแยก (`doc` / `gate N` / `hold:<reason>`) ครบทุกตัวพร้อมกัน (AC-072) · plan legacy → แถบ "ต้อง migrate" + ป้าย "dispatch ทีละตัว" (AC-074)
- **Inputs / Outputs:**

| Method/Path | Response |
|---|---|
| `GET /api/modules/<name>/tasks` | `{ planFormat: "v2"\|"legacy", needsMigration: bool, active: int, maxParallelSessions: int, tasks: [{ taskId, name, owner, planPhase, depends: string[], status: "pending"\|"verified"\|"blocked", step, attempt, fixRounds, fixRoundLimit, crashRestarts, sessionId: string\|null, hold: {reason, ref}\|null, waitingFor: string[] }], phases: [{ phase, featureQa: "not-ready"\|"queued"\|"running"\|"pass"\|"fail", cleared: bool }], waitingOnHuman: [{ source: "doc"\|"gate"\|"hold", text, gateId?, taskIds: string[] }] }` |
| `POST /api/modules/<name>/tasks/<taskId>/retry` | body `{ by: string, note?: string }` · ปลด hold `crash-limit`/`blocked`/`audit-violation`/`invalid-handoff`/`context-error`/`status-conflict`/gate 4 ที่ answered → event `human-retry` (R22 — DES-018) · 200 `{ taskId, step }` · ไม่ hold / hold ที่ปลดด้วยปุ่มนี้ไม่ได้ (`design-change`, `requirement-change`, gate open) → 409 · `by` ว่าง → 400 |
| `GET /api/sessions/<sessionId>` | `{ sessionId, kind, role, taskIds, camp, model, effort, basisReason, startedAt, endedAt, outcome, contextFiles: string[], writeAudit, priorSession, logTail: string }` (AC-047, AC-066) |

- `waitingFor` = Depends ที่ยังไม่ satisfied + เหตุคิว (`ceiling` / `claim:<sessionId>` / `quiesce` / `gate:<id>`) — คนเห็นว่าทำไมไม่รัน (AC-037/064)
- **Permissions / States / Errors:** อ่านอย่างเดียวยกเว้น `retry` · `retry` ไม่ reset ตัวนับ (DES-018) · บันทึก `{by, note, at}` ใน `TaskRuntime.humanActions[]` ตามที่ผู้ใช้พิมพ์ (AC-016 แนวเดียวกัน — ระบบไม่เขียนชื่อแทน) · module ไม่มี run → `tasks` จากเอกสารล้วน step = `waiting-deps`/`runnable`
- **Compatibility:** additive ต่อ DES-009 (endpoint ใหม่) · SSE event ต่อ task อยู่ DES-009
- **Data/schema · Migration:** อ่าน `TaskRuntime`/`SessionRecord` (data-model) · ไม่มี
- **Security:** loopback + Host check ตาม DES-009 · `retry` เป็น state-changing — ใช้ POST + ตรวจ `Origin` = `http://127.0.0.1:<port>` (กัน CSRF จากหน้าเว็บอื่นในเครื่อง) · `logTail` อาจมีเนื้อหาโค้ด/เอกสาร — local เท่านั้น
- **Fallback:** UI ล่ม → scheduler เดินต่อ, gate/hold แจ้ง terminal (DES-009)
- **Evidence:** DES-009 endpoints เดิม · `inferred`: ยังไม่มีโค้ด `src/web` (มีแค่ `.gitkeep` — Glob 2026-10-05)
