## DES-004 — Tier engine (port จาก orchestrator เดิม)

**Traces:** REQ-004 (AC-008, AC-009, AC-010) · ADR-022 `decisions\ADR-022-per-phase-model-tier.md:49-97`

**Rule:** แปลง `tierRouting.ts` มาเกือบ 1:1 โดยตัดสิ่งที่ระบบนี้ไม่มี (legacy frontmatter, camp zai, TTY prompt) Precedence คงเดิมทีละ field (`tierRouting.ts:140-153`, `tier-and-effort-run.md:46-56`): **operator/role override (routing.yaml `model`/`effort`) → tier ของ task → role default tier → ปฏิเสธ** — ค่าที่ชนะแยกกันระหว่าง model กับ effort ตามของเดิม ("ถ้า override แค่ effort, model จาก Tier ยังใช้ได้") กติกาที่ต้องคงไว้จากของเดิม: (1) ปฏิเสธ T1 เมื่อมาจาก task/config อัตโนมัติ พร้อมเหตุผลกำกับ (AC-009) — `tierRouting.ts:83-87`; (2) effort ของ tier ผูกกับ model ของ tier เดียวกัน — ถ้า override model ล้วน ๆ effort ตกไปเป็น runtime default ไม่ดึง effort ของ tier เดิม; (3) antigravity effort=null หมายถึง reasoning เลือกโดยชื่อ model เอง ห้ามส่งเป็น flag (`tier-and-effort-run.md:99`); (4) ทุกครั้งที่ resolve ต้องได้ `basis` (AC-008) ในรูป `tier=<T>,model=<basis>,effort=<basis>` — port จาก `formatModelPolicyBasis` (`tierRouting.ts:167-169`)

**Inputs/Outputs:** Input: `tiers.yaml`, `routing.yaml` (role route override), tier ที่ task/plan cast (ถ้ามี), camp ที่ DES-005 เลือก. Output: `{model, effort, effectiveTier, modelBasis, effortBasis, diagnostics[]}` — ถ้า task ไม่ระบุ tier ใช้ `role_defaults[role]` (REQ-004)

**Permissions/States/Errors:** parse ล้มเหลว → `ModelTiersInvalidError` แบบเดิม (`modelTiers.ts:41-44`) ระบุรายการปัญหา; tier ที่ไม่ใช่ T1–T6 → ปฏิเสธ; tier ที่ camp นั้นไม่มี cell → ปฏิเสธ (fail closed ไม่แทนค่าแทน) · **Compatibility:** additive · **Data/schema · Migration:** tiers.yaml ตั้งต้นตามตารางที่ยืนยันแล้วใน requirement (OQ-4) — แก้ไฟล์ต่อได้โดยไม่แตะโค้ด (AC-010); run ที่ freeze route ไว้แล้วใช้ค่าใน StageRecord ตอน resume ไม่เปลี่ยนตาม config ใหม่เงียบ ๆ · **Security:** ไฟล์นี้ไม่มี secret; "Cross-camp cells are approximations, not equivalences" คงเป็นหลักการ (`model-tiers.yaml:1-3`, ADR-022 §Decision 1) · **Fallback:** ไม่มี fallback อัตโนมัติข้าม camp — การเปลี่ยน camp เป็นการตัดสินของคน (ADR-022 §Consequences)
