## DES-003 — Role prompt แหล่งเดียว และวิธีแนบต่อ dispatch

**Traces:** REQ-003 (AC-006, AC-007), REQ-005 (AC-012)

**Rule:** ทุก dispatch อ่าน role prompt จาก `<packRoot>\.claude\agents\<role>.md` (`rolePromptRoot` — packRoot = `C:\src\AICode\rong-ngang\code\` — pack fork จาก sta2 สร้างใหม่โดย setup role ตาม task ใน plan (ยืนยัน 2026-10-05 — ไม่ชี้ sta2 อีกต่อไป; ย้ายเข้า `code\` แล้วบนดิสก์ 2026-10-05 เพราะ pack เป็น asset ของสินค้า agent-team — `code\` = ตัวสินค้าทั้งก้อน, `knowledge\` ผูกด้วย config เท่านั้น — DES-015)) ณ เวลา dispatch (ไม่มีสำเนาต่อ camp — AC-006) — prompt loader อ่านจากที่เดียวกับ solo mode (DES-013 — AC-023) แยก frontmatter ออกจากเนื้อ prompt ด้วย parser แบบแบน (port แนวจาก `agents/agentModel.ts:74-84` `parseFrontmatterField`) แล้วใช้: `tools:` → รายชื่อ tool ที่ปล่อยผ่านฝั่ง claude (`--allowedTools`) และเป็นข้อความ advisory ใน packet สำหรับ codex/agy; `model:`/`effort:` ใน frontmatter **ไม่ใช้เลย** — policy authority คือ tiers.yaml (เหตุผลเดียวกับ `docs\tier-and-effort-run.md:54-56`: frontmatter เป็น compatibility output ไม่ใช่ policy)

**วิธีแนบ:** claude → เนื้อ role prompt ผ่าน `--append-system-prompt-file` (ช่อง system prompt จริง แยกจาก user message) · codex/agy → เนื้อ role prompt วางเป็น section "ROLE PROMPT (ถือว่าเป็น system instruction)" บนสุดของ packet file ตามด้วย section "TASK BRIEF" (mark `inferred`: มีหลักฐานว่า CLI สองตัวนี้ไม่มีช่อง system prompt แยก; ประสิทธิภาพการถือตาม instruction ขึ้นกับ model และตรวจได้จากผล stage แรก)

**Inputs/Outputs:** Input: `rolePromptRoot`, ชื่อ role. Output: `rolePrompt.hash` (sha256) บันทึกใน StageRecord ทุก dispatch — เมื่อไฟล์เปลี่ยนระหว่าง run เดียว driver บันทึก hash ใหม่ต่อ stage เพื่อให้ log ระบุได้ว่าเวอร์ชันไหนรันจริง (แนวคิด log-only จาก `agentModel.ts:30-40`)

**Permissions/States/Errors:** ไฟล์ role ไม่มี/ว่าง → ปฏิเสธ dispatch ก่อน spawn; frontmatter ไม่มี `tools:` → ใช้ default อ่านอย่างเดียว (Read, Glob, Grep) และบันทึกเตือน · **Compatibility:** additive · **Data/schema · Migration:** ไม่มี · **Security:** role prompt เป็น input ที่เชื่อถือได้ (มาจาก packRoot ที่คนดูแล — fork จาก sta2 โดย setup role, ต้นฉบับ sta2 อ่านอย่างเดียว); hash กันการแอบเปลี่ยนกลางทางโดยไม่รู้ตัว · **Fallback:** rolePromptRoot เปลี่ยนที่ได้จาก registry.yaml — แก้ config จุดเดียว
